# Utility360 — aggiornamenti

Qui ci sono le versioni di Utility360 per chi ne ha una copia sul proprio GitHub e Cloudflare.

- `utility360.tar.gz.gpg` — l'ultima versione, cifrata (serve la password).
- `VERSIONE` — numero di versione e commit.
- `aggiorna.yml` — l'automazione da mettere nel proprio repo come `.github/workflows/aggiorna.yml`:
  ogni notte avvisa se c'è una versione nuova; l'installazione si avvia a mano e tiene le modifiche fatte a mano (se ce ne sono, prima chiede di controllarle). Le istruzioni sono in cima al file.
- `ISTRUZIONI-CLAUDE.md` — testo da dare a Claude per modificare la propria copia senza perdere gli aggiornamenti.
